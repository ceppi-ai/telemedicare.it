Trasparenza tecnica

Cookie policy.

Il sito, nella configurazione attuale, non installa cookie e non usa memoria locale. Ultimo aggiornamento: 25 agosto 2026.

Cosa usiamoGitHubLink esterniModifiche

1. Cookie e memoria locale

Nessun banner necessario nella configurazione attuale: Telemedicare.it non imposta cookie, non utilizza local storage, non integra strumenti pubblicitari, profilazione, social plugin o analisi del traffico.

I normali log tecnici dell’hosting non sono cookie del browser e sono descritti nella privacy policy.

2. File dati ospitati su GitHub

Per mostrare offerte e copertura aggiornate, il browser richiede file JSON pubblici a raw.githubusercontent.com. I file contengono soltanto dati editoriali. La richiesta comunica a GitHub i normali dati tecnici della connessione, come indirizzo IP, data, ora e browser, secondo la privacy statement di GitHub. Telemedicare.it non usa questa richiesta per profilazione o statistiche.

3. Collegamenti esterni

Le schede contengono link alle pagine ufficiali dei fornitori. I siti esterni si aprono solo dopo il clic dell’utente e applicano le proprie policy su cookie e dati personali. Telemedicare.it non incorpora video, mappe, widget di recensioni o contenuti social di terzi.

4. Modifiche future

Prima di introdurre statistiche, pubblicità o altre tecnologie non necessarie, valuteremo la base giuridica, aggiorneremo questa pagina e, quando richiesto, mostreremo un pannello di consenso che permetta di rifiutare con la stessa facilità con cui si accetta.

Per domande scrivi a privacy@telemedicare.it.
